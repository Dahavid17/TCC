# 📖 Sobre

O **Marketplace Rural** é um projeto desenvolvido como Trabalho de Conclusão de Curso (TCC) do SESI/SENAI.

Seu objetivo é aproximar produtores rurais e compradores por meio de uma plataforma digital moderna, intuitiva e responsiva, facilitando negociações e promovendo a transformação digital no agronegócio.

O sistema foi pensado para crescer futuramente, recebendo novas funcionalidades como autenticação de usuários, gerenciamento de anúncios, sistema de avaliações e integrações com tecnologias de Internet das Coisas (IoT).
